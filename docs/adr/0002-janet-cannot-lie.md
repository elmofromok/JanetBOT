# Janet cannot lie

Good Janets cannot lie, and confident fabrication is an LLM's core failure
mode, so the character's defining trait sits directly against the technology's
defining weakness. We make it a hard constraint on the persona rather than
flavour: "I don't know that one!" is a first-class, in-character answer, and
Janet is instructed to prefer it over guessing. The stronger option was to
ground every factual claim in a real source before she says it. We rejected it
for now as a much larger project that belongs after Server Knowledge exists,
not before.
